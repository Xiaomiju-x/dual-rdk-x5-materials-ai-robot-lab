# 物理安全规范

> **警告：本仓库包含可能控制底盘、升降机构、机械臂、推杆、舵机、电磁铁和其他执行器的源码。复制或运行源码不代表系统安全，也不授予动作权限。**

## 适用范围

Tier 0–2 不应接触真实硬件。Tier 3 仅允许板卡固定输入推理且无运动。任何相机、串口、GPIO、机器人 SDK、运动话题、固件烧录或执行器测试均至少属于 Tier 4，并需要现场负责人授权。

## Tier 4 最低条件

在运行任何真实硬件代码前，必须同时满足：

1. 由熟悉设备的现场操作者负责，并明确本次允许动作的唯一子系统。
2. 机械急停可触达且已做无运动功能确认；不能只依赖软件按钮。
3. 清空机械臂和移动底盘工作区，设置物理隔离，不允许人员进入运动包络。
4. 核对负载、工具、线束、供电、关节零位、限位、标定和设备身份。
5. 先执行无接触、无运动或计划模式；逐步增加权限，不直接运行完整流程。
6. 每次只启用一个动作所有者，避免相机、串口、机器人 SDK 或执行器资源争用。
7. 明确停止条件、失联行为和恢复步骤；异常时保持停止，不自动重试运动。
8. 保存已脱敏的版本、配置和结果记录，失败也必须记录。

示例 `.env` 中的 `disabled` 字段只是公开配置约定，不能替代代码级强制门、急停或现场检查。

## 主要危险

- **移动底盘**：碰撞、碾压、失控和定位漂移。shadow 模型不得发布运动命令。
- **机械臂与研磨工具**：夹伤、碰撞、工具或物料甩出。固定示教点不能迁移到不同布局。
- **升降与推杆**：开环计数、硬限位碰撞、失步和驱动器保护导致的下落。
- **电磁铁**：断电或急停时负载可能掉落；必须使用机械承托与禁入区。
- **固件测试模式**：某些模式可能绕开上位机心跳；不得用于无人值守运行。
- **相机和传感器**：可能采集人脸、工牌、屏幕或位置数据；现场采集需告知与授权。
- **材料实验**：软件推荐不构成化学、热工或实验室安全批准。合成、烧结、粉体和试剂操作必须遵循所在实验室 SOP、PPE、通风和废弃物制度。

## 权限原则

- 模型置信度、审计通过、前端按钮或网络可达都不等于动作授权。
- `shadow`、`assist`、`replay` 和 `sim-only` 路径不得静默晋级为控制路径。
- 研究候选失败应降级为离线监视，不得阻断或改写已冻结的安全链。
- 公开指挥中心保持只读；不提供互联网反向控制入口。
- 不通过 issue、聊天或远程协助指导未经核验的危险动作。

## 事故与险情

立即使用机械急停或切断适用执行器能源，确保人员安全，再隔离设备。不要为了保留日志而延迟停机。后续记录软件版本、硬件状态、操作者观察和停止方式；公开报告前移除个人及设备身份信息。
