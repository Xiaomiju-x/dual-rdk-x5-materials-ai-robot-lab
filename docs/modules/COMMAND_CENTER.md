# 指挥中心与公开证据站

指挥中心把项目状态、模型边界、运行证据与公开研究资源组织为只读页面。代码位于 [`web/command_center/`](../../web/command_center/)，归档静态快照位于 [`public_site_static/`](../../public_site_static/)。

## 设计边界

- 互联网展示层不反向控制 AI 脑、具身脑、机械臂或 STM32F407。
- 公开状态必须由脱敏、版本化的快照或受限只读接口提供。
- 外部站点不可用不应改变设备状态，也不是本地演示启动依赖。
- 截图和缓存是特定时间的证据，不等于当前 live 状态。
- 任何人物、现场、设备身份或实验数据在公开前都需完成隐私和许可审核。

## 离线审阅

无需启动服务即可在浏览器中打开 `public_site_static/index.html`。预期只呈现归档内容，不连接真实设备。动态后端与部署环境属于独立发布范围，不能从静态快照的存在推导为可公开部署或当前在线。

公开 API 形状与示例位于 [`schemas/`](../../schemas/)。当前发布树已通过无硬件契约测试、静态资源与文档链接检查；依赖和发布边界由 CI、SBOM 与发布审计持续核对。
