# STM32F407 执行层

STM32F407 固件实现底盘与实验助理机构的底层时序，包括升降、推杆、舵机、电磁铁和通信安全状态。源码位于 [`firmware/stm32f407/`](../../firmware/stm32f407/)。

## 公开内容

- 工程配置、板级支持、应用状态机与串口协议实现。
- 急停锁存、心跳失联处理和受限命令状态。
- 历史测试模式与故障记录，便于理解为什么某些机械路径被降级或冻结。

## 关键限制

- 升降位置主要依赖开环脉冲计数，不能等同于编码器闭环或双限位安全系统。
- 电磁铁断电可能导致负载掉落；软件急停不能替代机械承托和安全区域。
- 独立测试模式可能绕开上位机心跳合同，不能作为普通演示入口。
- ACK 表示命令被接受时，不一定表示机械动作已经物理完成。
- 固件、线束、驱动器电流、微步、行程和真实机构必须逐一匹配；不同硬件不可照搬参数。

烧录和运动属于 Tier 4。本公开导航不提供一键刷写或动作命令；必须由现场负责人使用目标硬件的版本化 runbook，并满足 [物理安全规范](../safety/PHYSICAL_SAFETY.md)。
