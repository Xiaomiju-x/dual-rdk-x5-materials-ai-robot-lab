# v1.0.1｜基于双 RDK X5 异构协同的材料合成 AI 预测与多机具身实验助理机器人

**2026 全国大学生嵌入式芯片与系统设计竞赛 · 芯片应用赛道 · 地瓜机器人赛题｜西南赛区一等奖**

本版本是项目的完整公开发布与准确性修订版。全国总决赛奖项仍待组委会正式公布，不预测、不预填。

## 本版本提供

- AI 脑、具身脑、双机械臂工作站、STM32F407、只读指挥中心与安全审计源码；
- 完整中英文首页、系统架构、模块导航、离线复现、证据矩阵、已知限制与物理安全分级；
- 用户指定的最新 6 张照片全部直接展示，包括保留二维码的项目海报和现场联调合影；
- 3 段可点击动态预览与静音 MP4：材料 AI / XRD、具身实验助理、双机械臂完整固定工位流程；
- 可确定性重建的 SPDX 2.3 SBOM、媒体来源清单和 SHA-256 校验文件；
- CI、CodeQL、Gitleaks、Markdown 链接、奖项单一事实源、媒体元数据与零硬件测试门。

## 准确性与安全修订

- 区域奖项统一为“西南赛区一等奖”，不再使用名次表述；
- 正式项目名、比赛全称、赛道与赛题信息已统一到 README、引用元数据、UI、SBOM 和发布资料；
- 历史语音服务凭据已从当前源码移除并改为环境变量读取；可达 Git 历史执行敏感数据清理，历史凭据仍须由所有者在服务端轮换或撤销；
- 修复路径注入、XSS、ReDoS、堆栈信息暴露和无效编码替换问题，并增加离线回归测试。
