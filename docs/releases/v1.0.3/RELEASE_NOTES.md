# v1.0.3｜基于双 RDK X5 异构协同的材料合成 AI 预测与多机具身实验助理机器人

**2026 全国大学生嵌入式芯片与系统设计竞赛 · 芯片应用赛道 · 地瓜机器人赛题｜西南赛区一等奖 · 全国总决赛二等奖**

本版本公开两张由中国电子教育学会颁发的官方获奖证书，并把两项成绩从仅队伍确认升级为可审计的 `certificate_verified`。证书文件、证书编号、颁发机构、签发月份、核验日期和 SHA-256 统一绑定到奖项唯一事实源。

## 本版本更新

- README 与英文首页直接展示“西南赛区一等奖”和“全国总决赛二等奖”两张完整证书；
- 证书公开件与用户提供 PNG 逐字节一致，不裁切、不打码、不修改画面；
- 媒体清单扩展为 22 项，并确认两张证书不含 EXIF、GPS、XMP、ICC 或文本元数据；
- 奖项渲染器、发布审计和零硬件测试增加 `certificate_verified` 状态、证书字段完整性与 SHA-256 防篡改门；
- 奖项页、官方来源页、证据索引、断言矩阵、已知限制、引用元数据和版本记录同步更新；
- 不把仓库内证书链接伪装成独立的组委会成绩网页；未来获得稳定官方 URL 后可继续升级证据状态。
