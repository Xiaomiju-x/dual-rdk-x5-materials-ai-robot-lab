# 已知限制

本页列出当前证据不能支持的结论。它是公开项目的一部分，不是待删除的“负面说明”。

## 材料任务与数据

- 近红外荧光粉是团队完成真实验证的材料载体；不能据此宣称覆盖全部集成电路材料或晶圆厂工艺。
- JARVIS-DFT、SECOM、NIST SEM 等结果属于版本化公开基准。计算数据不是实验 ground truth，匿名历史制程数据不是团队产线数据，模拟 SEM 图像不是实际晶圆缺陷。
- 私有或逐文档授权的 XRD/PL/RAG 内容不能因源码开源而自动再分发。
- 教师模型和 API 输出只能生成候选标注，不能直接成为科学事实。

## AI 脑

- 50 个唯一逻辑模型的 PC release-ready 是合同、资产、证据和发布门结论，不表示 50 个模型都在 X5 上通过。
- 49 个 X5-local 模型是按需模型库，不是同时常驻或并发运行。
- 新增 38 个候选中仍有 4 个 experimental 和 3 个 rejected；这些状态是最终结果的一部分。
- 三套分段 BPU LLM 虽完成 actual BPU 执行，但固定 next-token 不一致，不支持通用自由生成、问答正确率或 FP32 语义一致性主张。
- PC OpenExplorer 编译记录不是 actual X5 延迟、内存或语义差分。
- 标记为 `SIM_ONLY` 或 `QUALITY_LIMITED_NOT_PROMOTED` 的任务不能作为实机效果锚点。

## 具身脑

- v5r1 验收使用固定合成/标定张量，证明固定合同、延迟与恢复门，不证明真实相机准确率或持续导航性能。
- 当前没有足够证据证明候选完成了同步 LiDAR、深度、IMU、里程计和视觉的实时融合闭环。
- 集成 Cortex 保持 `MONITOR_OFFLINE`；研究候选没有运动、TF、服务、串口或 F407 权限。
- 冻结移动演示的成功不能被外推为任意场景自主导航成功率。

## 双机械臂与固件

- 冻结 v3 动作链针对固定机械布局、工具和任务；不代表未见物体、不同工作站或不同机械臂的泛化。
- Tiny-ACT、世界模型和技能分类结果基于 fixture 或 replay，不是真实学习策略成功率。
- 阶段分类头通过不等于动作头、同步头或下一技能头都通过。
- STM32F407 升降包含开环计数和历史降级路径，不能替代限位、编码器、机械承托和现场急停。
- 电磁保持件失电可能掉落，机器人和研磨工具存在夹伤、碰撞、甩出与粉尘风险。

## 公开仓库与复现

- 源码公开不等于所有模型权重、数据集和现场配置均可再分发；具体见 [公开边界](../safety/PUBLICATION_BOUNDARY.md)。
- 公开边界、仓内链接、奖项一致性、确定性 SBOM、零硬件测试、离线 demo 和工作站前端构建门已通过。这些工程门不证明未进入测试的可选环境、科学效果或真机安全。
- 归档截图、静态站点和回执反映特定时间点，不是实时服务承诺。
- 硬件复现高度依赖器件版本、标定和场地，不提供远程安全保证。
