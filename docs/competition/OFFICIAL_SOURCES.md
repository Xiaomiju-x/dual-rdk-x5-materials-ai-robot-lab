# 竞赛官方与公开来源

下列链接用于核对比赛名称、赛道、赛题和公开通知。链接能证明的范围必须与具体成绩证明分开。

| 来源 | 用途 | 不能单独证明 |
| --- | --- | --- |
| [全国大学生嵌入式芯片与系统设计竞赛通知页](https://www.socchina.net/wx/inform?value=3) | 比赛与组委会公开通知入口 | 本队具体名次或奖项 |
| [2026 地瓜机器人赛题页](https://www.socchina.net/wx/details?id=5e7b974c879a4fc5a60e27eff1f2e5f8&value=3) | 赛题归属与公开资料入口 | 本队区域排名或全国奖项 |
| [地瓜机器人开发者论坛赛题资源](https://forum.d-robotics.cc/t/topic/34303) | 平台与赛题资料 | 竞赛成绩 |
| [西南赛区公开结果页面](https://www.fpgachina.cn/details?id=e98e50a25c8b499bb03db435dae84044) | 西南赛区公开名单/晋级背景 | 不单独作为“西南赛区一等奖”的充分获奖来源 |
| [西南赛区一等奖官方证书](../../assets/media/certificates/southwest-regional-first-prize-certificate.png) | 西南赛区一等奖 | `certificate_verified`；中国电子教育学会颁发，文件哈希见奖项事实源 |
| [全国总决赛二等奖官方证书](../../assets/media/certificates/national-final-second-prize-certificate.png) | 全国总决赛二等奖 | `certificate_verified`；中国电子教育学会颁发，文件哈希见奖项事实源 |

两项奖项现均有官方证书公开件，但尚未把第三方网页或媒体报道当作官方成绩页。若组委会后续提供稳定 HTTPS 获奖页面，只在 [`award_status.yaml`](award_status.yaml) 中增加该来源，再由展示生成流程更新 README 与 [AWARDS.md](AWARDS.md)。

若公开页面后续变化，应保存合法的静态证明、记录获取日期和 SHA-256；不得编辑截图制造名次，也不得用媒体报道替代相冲突的官方名单。
