# DualArm-ShadowVLA 真实性边界

版本：v1
日期：2026-07-30

## 1. 总原则

决赛现场动作仍由已真机验收并冻结的双臂 v3 确定性流程完成。学习候选只对
动作完成后的证据副本执行 `POST_RUN_REPLAY`。任何表述都不得把“离线建议、
蒸馏、编译、影子推理”升级为“学习模型控制机械臂”。

固定事实：

```text
MOTION AUTHORITY = FROZEN V3
SHADOW EXECUTION ALLOWED = FALSE
SHADOW ACTUATOR COMMANDS ISSUED = 0
```

## 2. 可直接说

以下表述在对应证据存在时可以使用：

- “复赛冻结 v3 是双机械臂唯一运动权威。”
- “DualArm-ShadowVLA 对已完成动作的双相机和双臂 13D 数据做离线回放。”
- “13D 包含 arm01 六关节、arm01 G23 和 arm02 六关节。”
- “候选预测阶段、下一技能、动作块、双臂同步、任务结果和 OOD。”
- “SmolVLA 是轻量 VLA 候选，ACT 是动作分块基线。”
- “X5-BiSkill Shadow 计划由 BPU 执行轻量学生前向，CPU 负责时间对齐、
  规则一致性、OOD 和证据落盘。”
- “影子算法即使退出或失败，也不会影响冻结 v3 完成动作。”
- “Xiaomi XR-0 是开放 VLA 参考；XR-U0 是 38B 世界生成模型参考。”
- “XR-1 的大规模 UMI 预训练方法是研究参考。”
- “所有影子产物固定记录零执行命令。”

“训练完成”“转换通过”“X5 真机运行”等完成态，只能在相应
`model_receipt_v1` 回执和哈希存在时使用。

## 3. 必须限定后再说

| 主题 | 必须使用的限定 |
|---|---|
| VLA | “VLA-derived / VLA 候选 / 离线影子策略”，不能省略影子边界 |
| X5 部署 | 必须区分“转换候选”“编译通过”“X5 板端实测” |
| BPU 性能 | 只能引用真实板端计时；编译器估算必须明确称“编译器估算” |
| 双臂智能 | 可说“学习双臂阶段与动作块”，同时说明动作仍由冻结 v3 执行 |
| 闭环 | 冻结 v3 可称物理闭环；学习候选只能称离线回放闭环或证据闭环 |
| 世界模型 | 只能说预测后续阶段、袋状态、同步与成功概率，不说物理仿真已替代真机 |
| XR-0 | 只能说参考、离线实验或教师；项目适配状态由本项目回执决定 |
| XR-1 | 只能说方法参考；截至 2026-07-30 官方仓库仍写明代码/权重待发布 |
| XR-U0 | 只能说世界模型/合成参考，不得称为动作控制 VLA |
| SmolVLA | 未训练前称候选；训练后仍须说明数据规模和离线评测范围 |
| OpenVLA-OFT | 称重型教师/对标；没有实际回执时不说已训练或已适配 |
| OOD | 可说“检测并标记 UNKNOWN/不确定”，不说能够覆盖所有未知风险 |
| 工业价值 | 可说“面向可审计、可降级的工业研究路径”，不说已获生产认证 |

- “VLA 已控制两台机械臂完成现场动作。”
- “学习模型替换了复赛 v3。”
- “X5 运行了完整 SmolVLA、XR-0、XR-U0 或 OpenVLA-OFT。”
- “X5 部署了 38B 小米机械臂模型。”
- “XR-U0 是直接输出本项目机械臂动作的 VLA。”
- “XR-1 已开源并被本项目训练或部署。”
- “已经实现端到端自然语言零样本双臂控制。”
- “动作预测经过安全门后会自动下发。”
- “shadow 可以阻止、修正或接管冻结 v3。”
- “编译器 FPS/延迟等于 X5 真机性能。”
- “合成数据指标等于真实机械臂成功率。”
- “一次成功演示证明模型具有泛化能力。”
- “模型消除了碰撞、掉袋、卡死或舵机风险。”
- “具备工业生产认证、无人监管运行或功能安全等级。”
- “世界领先、全球第一、所有其他方案都不具备。”

## 5. 演示屏固定标识

影子结果页面必须持续显示：

```text
MODE: POST_RUN_REPLAY
MOTION AUTHORITY: FROZEN V3
SHADOW MOTION AUTHORITY: FALSE
SHADOW EXECUTION ALLOWED: FALSE
SHADOW ACTUATOR COMMANDS: 0
```

若模型、数据、时钟或相机证据不完整，页面应显示 `UNKNOWN`、
`SHADOW_DEGRADED` 或 `SHADOW_OFFLINE`，不得隐藏降级。

## 6. 证据等级

按以下顺序陈述，不得跨级：

1. `REFERENCE_ONLY`：只有论文/代码调研。
2. `CONTRACT_VALIDATED`：Schema 和边界测试通过。
3. `OFFLINE_REPLAY`：在冻结证据副本上产生可复现结果。
4. `GPU_TRAINED`：存在训练配置、日志、checkpoint 哈希和留出集结果。
5. `BPU_COMPILED`：Bayes-e 转换通过，但还不是板端实测。
6. `X5_BOARD_VALIDATED`：真实 X5 前向、资源和非干扰回执通过。
7. `LIVE_SHADOW_LOW_RATE`：未来候选等级，本合同未授权。
8. `ASSIST_CANDIDATE`：未来研究等级，本合同未授权。

无论达到哪一级，当前候选均保持：

```json
{
  "motion_authority": false,
  "execution_allowed": false,
  "actuator_commands_issued": 0
}
```

## 7. 推荐答辩口径

> 现场动作由已经真机验收的确定性双臂流程独立完成。我们在它之后增加了
> 一个没有运动权限的 DualArm-ShadowVLA：它读取两路相机和双臂 13D
> 证据，离线预测阶段、动作块、协同状态和结果；再把能力蒸馏到 RDK X5
> 的轻量学生模型。这样既能研究 VLA 和世界模型，又不让尚未完成安全验证
> 的学习策略影响现场执行。

## 8. 发布前检查

- 所有 JSON 通过对应 Schema。
- 所有页面与报告包含零运动权限三元组。
- 所有模型完成态均有回执和哈希。
- 所有外部资产均有来源与许可记录。
- 冻结 v3 哈希未变化。
- 候选没有机器人 SDK、串口、GPIO、PWM、G23 或动作发布路径。
- 候选停止时，冻结 v3 仍可独立完成演示。
