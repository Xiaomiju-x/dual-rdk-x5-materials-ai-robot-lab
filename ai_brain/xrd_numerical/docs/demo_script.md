# XRD智能分析系统 竞赛现场演示脚本

## 系统概述 (30秒口述)
本系统实现了从Bruker XRD原始.raw二进制文件到智能物相鉴定的全自动化流程，
部署在地平线RDK X5开发板上，利用BPU(Bayes-e架构)实现INT8量化加速推理。

核心技术: 两级BPU级联分类 + 晶体学峰位匹配引擎 + 大模型RAG增强报告

---

## 演示流程

### Step 1: 启动Web Demo (10秒)
```bash
python3 web_demo.py --port 8080
```
在笔记本浏览器访问 `http://<X5-IP>:8080`

(备选终端模式): `python3 demo.py <file.raw>`

---

### Step 2: 演示石榴石样品 (60秒)
**文件**: `CaLu2Sc2Al2SiO12.raw`
**预期结果**:
- 一级分类: garnet (>95%)
- BPU与CPU一致 ✓
- 峰匹配: Ia-3d石榴石, 得分>0.8
- 报告: 正确描述石榴石结构A₃B₂C₃O₁₂

**讲解要点**:
- "BPU推理延迟仅约Xms，相比CPU numpy推理实现了Nx加速"
- "峰位匹配引擎自动与17个标准晶相进行数值比对，给出最佳匹配"
- "系统自动识别出Ia-3d空间群并匹配到PDF参考卡片"

---

### Step 3: 演示非石榴石样品 (60秒)
**文件**: `Sr3YGa2O7.5-0.13BI.raw`
**预期结果**:
- 一级分类: non_garnet
- BPU-CPU仲裁机制触发(BPU给garnet但CPU给non_garnet → 采用CPU)
- 峰匹配: 单斜C2相, 匹配SYGO结构
- 报告: 正确描述单斜晶系结构

**讲解要点**:
- "BPU INT8量化精度有损，我们设计了BPU-CPU双通道仲裁机制"
- "当BPU(INT8)与CPU(float32)结果不一致时，自动采用float32精确结果"
- "这保证了量化模型的鲁棒性，同时不牺牲BPU加速展示"

---

### Step 4: 演示OOD拒识 (60秒)
**文件**: `In2O3.raw` 或 `CaLaGa3O7.raw`
**预期结果**:
- 一级分类: non_garnet
- 二级分类: 置信度<55% → 触发OOD拒识
- 拒识后转峰匹配: bixbyite(Ia-3) 或其他匹配相
- 交叉验证: 以峰匹配为准

**讲解要点**:
- "当细分类置信度不足时，系统自动拒绝不可靠的神经网络输出"
- "转由基于物理的晶体学峰位匹配引擎进行鉴定"
- "这体现了AI判断与物理先验知识的融合"

---

### Step 5: 展示BPU性能 (30秒)
```bash
python3 benchmark_bpu.py --samples 100
```
**预期输出**: BPU vs CPU延迟对比表，加速比>3x

**讲解要点**:
- "100次推理的统计基准测试，P50/P95延迟全面领先"
- "BPU INT8量化推理吞吐量达到N推理/秒"

---

### Step 6: 批量处理 (20秒)
```bash
python3 demo.py --batch data/raw_files/ --offline
```
展示批量处理汇总表
