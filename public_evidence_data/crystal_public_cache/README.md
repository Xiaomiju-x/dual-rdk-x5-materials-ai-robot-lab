# Crystal structure references

The previous review snapshot embedded CIF files from several databases. They
are intentionally not redistributed in this source release because database
terms can differ from the Apache-2.0 license of the team's code.

The reproducibility inputs are the following public identifiers. Obtain each
record from its authoritative provider under that provider's current terms,
then record the downloaded file hash in your local experiment manifest.

## Generated structures and relaxation outputs

Generated CIF archives and CHGNet, MatterGen, and MatterSim relaxation outputs
are also omitted until every model/data dependency has a documented
redistribution permission. The source and evaluation code remains available;
see [the data provenance guide](../../docs/data/PROVENANCE.md).
